# Веб-оболочка HH Applicant Tool

## Описание

Плагин `web-shell` предоставляет удобный веб-интерфейс для взаимодействия с HH.RU API через браузер. Это позволяет выполнять все операции без необходимости использования командной строки.

## Возможности

- 🌐 **Веб-интерфейс**: Удобный графический интерфейс в браузере
- 🚀 **Быстрые действия**: Предустановленные кнопки для часто используемых операций
- 🔧 **Произвольные запросы**: Возможность выполнения любых API запросов к HH.RU
- 📊 **Форматированный вывод**: Красивое отображение JSON ответов
- 🔒 **Локальная работа**: Все запросы выполняются локально на вашем компьютере
- 📱 **Адаптивный дизайн**: Работает на всех устройствах

## Установка

Веб-оболочка включена в основной пакет `hh-applicant-tool` и не требует дополнительных зависимостей. Используются только стандартные библиотеки Python.

## Запуск

### Базовый запуск

```bash
hh-applicant-tool web-shell
```

После запуска веб-сервер будет доступен по адресу `http://127.0.0.1:8080`, и браузер откроется автоматически.

### Параметры запуска

#### Изменение порта

```bash
hh-applicant-tool web-shell --port 9000
```

#### Изменение хоста

```bash
# Для доступа из локальной сети
hh-applicant-tool web-shell --host 0.0.0.0
```

#### Запуск без автоматического открытия браузера

```bash
hh-applicant-tool web-shell --no-browser
```

#### Комбинированные параметры

```bash
hh-applicant-tool web-shell --host 0.0.0.0 --port 9000 --no-browser
```

### Получение справки

```bash
hh-applicant-tool web-shell -h
```

## Использование

### Авторизация

⚠️ **Важно**: Перед использованием веб-оболочки необходимо авторизоваться:

```bash
hh-applicant-tool authorize
```

После успешной авторизации токены будут сохранены в конфигурационном файле, и веб-оболочка сможет их использовать.

### Быстрые действия

В веб-интерфейсе доступны предустановленные кнопки для часто используемых операций:

- **👤 Моя информация** - получить информацию о текущем пользователе (`/me`)
- **📄 Мои резюме** - список ваших резюме (`/resumes/mine`)
- **💬 Мои отклики** - список ваших откликов на вакансии (`/negotiations`)
- **🔍 Поиск вакансий** - быстрый поиск вакансий по Python (`/vacancies`)

### Произвольные API запросы

Вы можете выполнять любые запросы к HH.RU API:

1. Выберите HTTP метод (GET, POST, PUT, DELETE)
2. Укажите эндпоинт (например: `/me`, `/vacancies`, `/resumes/mine`)
3. Добавьте параметры в формате JSON (опционально)
4. Нажмите "Выполнить запрос"

#### Примеры запросов

##### Получить информацию о пользователе
- **Метод**: GET
- **Эндпоинт**: `/me`
- **Параметры**: (пусто)

##### Поиск вакансий
- **Метод**: GET
- **Эндпоинт**: `/vacancies`
- **Параметры**:
```json
{
  "text": "python developer",
  "per_page": 10,
  "area": 1
}
```

##### Получить список резюме
- **Метод**: GET
- **Эндпоинт**: `/resumes/mine`
- **Параметры**: (пусто)

##### Откликнуться на вакансию
- **Метод**: POST
- **Эндпоинт**: `/negotiations`
- **Параметры**:
```json
{
  "vacancy_id": "12345678",
  "resume_id": "abcdef123456",
  "message": "Здравствуйте! Меня заинтересовала ваша вакансия..."
}
```

## Безопасность

- 🔒 Все запросы выполняются локально на вашем компьютере
- 🔐 Токены доступа хранятся в конфигурационном файле и не передаются никуда
- 🌐 По умолчанию сервер доступен только с локального компьютера (127.0.0.1)
- ⚠️ Если вы открываете доступ из сети (--host 0.0.0.0), убедитесь, что понимаете риски

## Остановка веб-оболочки

Для остановки веб-сервера нажмите `Ctrl+C` в терминале, где был запущен сервер.

## Устранение неполадок

### Порт уже используется

Если порт 8080 уже занят другим приложением:

```bash
hh-applicant-tool web-shell --port 8081
```

### Ошибка "Не авторизован"

Если вы видите ошибки авторизации, выполните:

```bash
hh-applicant-tool authorize
```

### Браузер не открывается автоматически

Если браузер не открывается автоматически, откройте вручную адрес, указанный в терминале (обычно `http://127.0.0.1:8080`).

## Дополнительные возможности

### Использование с разными конфигами

Вы можете использовать разные конфигурационные файлы:

```bash
hh-applicant-tool -c /path/to/config.json web-shell
```

### Отладочный режим

Для получения дополнительной информации о запросах:

```bash
hh-applicant-tool -vv web-shell
```

### Использование прокси

Если в конфигурационном файле указан прокси, он будет использоваться для всех API запросов.

## Примеры использования

### Сценарий 1: Просмотр откликов

1. Запустите веб-оболочку:
   ```bash
   hh-applicant-tool web-shell
   ```

2. Нажмите кнопку "💬 Мои отклики"

3. Просмотрите список ваших откликов в отформатированном виде

### Сценарий 2: Поиск и отклик на вакансию

1. Выполните поиск вакансий:
   - Метод: GET
   - Эндпоинт: `/vacancies`
   - Параметры: `{"text": "python", "area": 1}`

2. Найдите подходящую вакансию и скопируйте её ID

3. Откликнитесь на вакансию:
   - Метод: POST
   - Эндпоинт: `/negotiations`
   - Параметры: `{"vacancy_id": "ID", "resume_id": "ваш_resume_id"}`

### Сценарий 3: Обновление резюме

1. Получите список резюме:
   - Метод: GET
   - Эндпоинт: `/resumes/mine`

2. Обновите резюме:
   - Метод: POST
   - Эндпоинт: `/resumes/{resume_id}/publish`
   - Где `{resume_id}` - ID вашего резюме

## Ограничения

- Веб-оболочка использует те же лимиты API, что и остальные команды
- HH.RU имеет лимиты на количество запросов (задержка между запросами настраивается)
- Лимит на количество откликов - 200 в день
