# Руководство по массовой рассылке откликов через Web Shell

## Запуск

1. Сначала авторизуйтесь (если еще не авторизованы):
```bash
hh-applicant-tool authorize
```

2. Запустите веб-оболочку:
```bash
hh-applicant-tool web-shell
```

Браузер откроется автоматически на `http://127.0.0.1:8080`

## Использование массовой рассылки

### Шаг 1: Найдите раздел "🚀 Массовая рассылка откликов"

Раздел находится на главной странице веб-интерфейса, сразу после "Быстрых действий".

### Шаг 2: Настройте параметры

- **ID резюме** (опционально): Оставьте пустым для автоматического выбора основного резюме
- **Поисковый запрос** (опционально): Например, "python разработчик москва" - для фильтрации вакансий
- **Тип графика** (опционально): Выберите удаленную работу, полный день и т.д.
- **Сопроводительное письмо** (опционально): Ваш текст или оставьте пустым для стандартного
- **Тестовый режим**: Включите для проверки без отправки реальных откликов

### Шаг 3: Запустите рассылку

Нажмите кнопку **"🚀 Начать массовую рассылку"**

### Шаг 4: Отслеживайте прогресс

В реальном времени вы увидите:
- 📊 Количество найденных вакансий
- ✅ Сколько откликов отправлено
- ⏭️ Сколько вакансий пропущено
- ❌ Количество ошибок
- 📝 Подробный лог всех операций

### Остановка рассылки

В любой момент можете нажать кнопку **"⏹️ Остановить"** для прекращения рассылки.

## Примеры использования

### Пример 1: Простая рассылка на все подходящие вакансии
- Оставьте все поля пустыми
- Нажмите "Начать массовую рассылку"

### Пример 2: Рассылка только на удаленные вакансии Python
- Поисковый запрос: `python`
- Тип графика: `Удаленная работа`
- Нажмите "Начать массовую рассылку"

### Пример 3: Тестовый запуск
- Включите чекбокс "Тестовый режим"
- Настройте остальные параметры
- Нажмите "Начать массовую рассылку"
- Посмотрите на что бы откликнулись без реальной отправки

## Переменные в сопроводительном письме

Вы можете использовать следующие переменные в тексте письма:
- `{vacancy_name}` - название вакансии
- `{employer_name}` - название компании
- `{first_name}` - ваше имя
- `{last_name}` - ваша фамилия

Пример:
```
Здравствуйте! Меня зовут {first_name} {last_name}.
Меня заинтересовала ваша вакансия {vacancy_name}.
```

## Ограничения

- HH.RU имеет лимит в 200 откликов в день
- Рассылка автоматически остановится при достижении лимита
- Между откликами автоматически добавляется задержка (1-3 секунды)

## Безопасность

- Все запросы выполняются локально на вашем компьютере
- Данные не передаются на сторонние серверы
- Веб-интерфейс доступен только с вашего компьютера (127.0.0.1)

## Устранение проблем

### "Ошибка: Не авторизован"
Выполните команду авторизации:
```bash
hh-applicant-tool authorize
```

### "Достигнут лимит откликов"
Это нормально - HH.RU ограничивает количество откликов в день. Попробуйте на следующий день.

### Веб-оболочка не запускается
Убедитесь, что порт 8080 свободен, или используйте другой:
```bash
hh-applicant-tool web-shell --port 8081
```
